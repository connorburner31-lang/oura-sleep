Privacy Policy

Last updated: October 18, 2026

This application is a personal-use tool operated by its owner for the owner's own use only.

What it accesses

The application reads the owner's own Oura Ring data through the official Oura API, limited to the daily scope (daily summaries of sleep, activity, and readiness). It does not access any other person's data.

How data is used

Data retrieved from the Oura API is used solely to present the owner's own sleep information back to the owner. No data is sold, shared with third parties, used for advertising, or used to train any model.

Storage

No personal data is stored on this website. This site hosts only static informational pages. API credentials are stored privately by the owner and are never exposed on this site.

Contact

For questions about this policy, contact the site owner through the GitHub repository associated with this site.
